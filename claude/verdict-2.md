# JOB 14 — the second verdict (chore/verdict-2, REPORT ONLY)

The run mode now exists as a real mode (JOB 1: `feat/run-mode` — a menu card, a 10-round run,
per-round CHAIN/FUSE/SAT with drafted modifiers, a visible ante wall, a loss condition, wins scaled
to the round reached). The original verdict named exactly this as the fix. So: does building it change
the answer?

## The one-sentence answer

**Mostly no — because we built the right thing and then buried it.** The original said make the run
mode "the flagship the menu leads with." We shipped it **gated behind level 30 (322,620 XP)**. That is
the *opposite* of leading with it. The single highest-leverage change in the game is now invisible for
the entire window in which a player decides whether to stay. The verdict stands, with one word changed:
the game is no longer *missing* its compelling loop — it is **hiding** it.

## Is this game good?

Same as before: **yes as craft, not yet as a thing people can't put down** — and the reason is now
sharper, not softer. Before, the defence was "the compelling loop doesn't exist yet." That defence is
gone. The loop exists, it's well-tuned (34.5% greedy win rate, deaths clustered R6–8, a real
draft decision every round), and a player who reaches it will feel the "one more run" pull the rest of
the game lacks. But reaching it costs ~LV30 of grinding the very modes whose moment-to-moment typing
wasn't compelling enough to carry the game in the first place. We put the cure at the far end of the
disease.

## What a stranger says after five minutes — did it change?

**No. Almost verbatim the same five minutes.** A new player is LV1. Run mode's card is on the menu but
locked ("LV30 — 29 to go"). So the stranger still meets: an empty Word Bomb lobby, an empty Category
Blitz, then the solo modes and a wall of progression systems, and still asks *"what am I supposed to be
doing?"* The one screen that answers that question is dark. The only thing that changed in the first
five minutes is that the player can now *see the locked poster of the game they're not allowed to play
yet* — which, if anything, is a crueler first impression, not a better one.

The stranger's experience only changes if they grind for hours. Almost none will.

## Does the run mode change the answer, or just add surface?

This is the fair question and the honest answer is split:

- **It is NOT just surface.** Structurally it's the real thing — a meta-loop that turns "type words
  fast" into "assemble a broken build," reusing the already-computed rarity × combo × lucky engine. A
  good meta genuinely rescues an OK core (Balatro's base poker is dull; the jokers make it). Run mode is
  the correct *kind* of addition, and it's built with real care.
- **But as DEPLOYED, it functions as surface** — because the people who need it (new players deciding
  whether this game is worth their time) never touch it. A cure nobody can reach is, from the player's
  side, indistinguishable from no cure. So the *product* barely moved even though the *game* gained its
  most important loop.

## The two things that would actually change the verdict

1. **Move the LV30 gate to the front.** Lead with run mode, or gate it at ~LV3–5, or — best — offer an
   immediate "try a 3-round run" taster at LV1 that then says "unlock the full 10-round run at LV_n_."
   The compelling loop must be reachable inside the first session. Right now the ordering is exactly
   inverted from the original recommendation. This is a small change (a gate constant + a menu-ordering
   decision) with the largest payoff available.
2. **Stop leading with the empty party.** Run mode existing doesn't fix multiplayer — Word Bomb /
   Category Blitz are still the marketed headline and still open to empty lobbies (JOB 4 adds
   life-signs and JOB B/mp-grace make a drop survivable, both good, but neither manufactures opponents).
   Demote multiplayer from the featured slot and give it to the mode that works from player one.

## Still-standing criticisms from verdict 1 (unchanged by JOB 1)

- **Too many systems, too little spine.** Run mode adds an *eleventh* system on top of ten; it should
  have *replaced* the buffet as the spine, not joined it. The fix is still: reveal 3–4 systems that feed
  the core loop, unlock the rest.
- **CHAIN and FUSE still overlap** — and run mode leaning on them per-round actually *raises* the case
  for merging them into one "constraint" mode and pouring the freed attention into more run-mode
  modifiers / round variety.

## Bottom line (harsh, as asked)

The team read verdict 1 correctly and built the exactly-right thing — and then shipped it in the one
configuration that neutralises it. This is a better game than it was a week ago and a **barely
different product**, and the distance between those two facts is a single number: the unlock level.
Ship run mode as the front door and the answer to "is this game good?" can finally flip to *yes*. Leave
it at LV30 and we will have built the cure, locked it in the cabinet, and kept complaining about the
disease. **Move the gate.**
