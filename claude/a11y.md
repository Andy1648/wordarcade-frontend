Two distinct issues, plus contrast (separate section):

### 1. SERIOUS — `aria-prohibited-attr` (room) — FIXED
`WaveText.jsx` wrapped the animated room code in a bare `<span aria-label="ABCD">`. `aria-label`
is **prohibited on a span with no role**, so screen readers may ignore the label entirely — the
room code (the one thing a joiner needs to read aloud) was effectively unlabelled. **Fixed:** added
`role="img"` to that span, so the label is permitted and the whole code is announced once while the
per-letter animation spans stay `aria-hidden`. (This is the only element in the app using that
pattern, so it's a one-line, whole-app fix.)

### 2. MODERATE — `region` (every screen) — REPORTED, not blind-fixed
"All page content should be contained by landmarks." The primary screen content is not inside a
`<main>` landmark, and app-level fixed controls (the `AudioControls` sound button, rendered outside
the screen at `App.jsx:2163`) sit outside any landmark too. **Why not fixed here:** the app renders
through a transition wrapper (`.view-screen`, briefly TWO during a wipe) with portaled/fixed
overlays — a correct single-`<main>` landmark is a considered structural change (naïvely tagging
`.view-screen` as `<main>` yields two `<main>`s mid-transition, itself a violation), so it was left
for a supervised change rather than risked blind. **Recommended fix:** one `<main>` around the
rendered screen at rest + put `AudioControls`/corner-nav in landmarks (the corner nav already uses
`<nav>`); expect `region` to drop to 0 across the board.

## Keyboard / focus

  everywhere) — tab order follows DOM order, which is correct.
- Tabbable counts are sane (menu 12, shop 18, room/credits/ingame 3–7).
- The global `:focus-visible` ring (`index.css:77`, 3px yellow) is present app-wide — good.

## Colour contrast — REPORTED, not fixed (per instruction: don't chase locked-palette contrast)
axe flagged contrast nodes: **stats 16**, ingame-word-bomb 3, credits 2, dialog 1, browser 1,
room 1. These are almost entirely the muted-lavender secondary text (`#b9a7d6`/`#d8c9f0`/… — see
the visual audit's "8+ muted-lavender shades") on the dark panel, and yellow/cyan on mid-tones.
They are on the locked house palette, so per the brief they are reported, not changed — but the
**stats screen (16 nodes) is the worst** and worth a deliberate contrast pass (the muted-text token
consolidation from the visual audit would fix most in one place).
